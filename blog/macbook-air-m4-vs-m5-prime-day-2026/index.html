M4 or M5: what is actually different

Apple launched the M5 MacBook Air in March 2026. At launch the 13-inch started at $1,099 and the 15-inch at $1,299, with 16GB of memory and 512GB of storage as the base configuration, according to coverage of Apple's announcement at the time (Engadget). That was $100 above the M4 Air's $999 starting price, and the base storage doubled from 256GB to 512GB. Apple also moved to its N1 wireless chip, which adds Wi-Fi 7 and Bluetooth 6, and says memory bandwidth is higher than on the M4.

Those are launch figures. Prices, configurations and stock change, so check Apple's current listing and the exact Amazon variant instead of relying on this page for a price. We also don't publish performance percentages, because we haven't benchmarked either machine.

Which one fits which buyer

  • Most students and everyday users: for browsing, documents, video calls and coursework, either chip is capable. The better question is the total price for the memory and storage you actually need.
  • Storage matters: because the M5's base storage is higher, compare like for like. An M4 with a storage upgrade can end up near the price of a base M5, so price the same configuration on both.
  • Heavy work: if you edit video, run local AI models or keep a lot of apps open, look at independent benchmarks for your workload, and consider more memory.
  • Keeping it a long time: a newer chip can help if you plan to keep the laptop for many years, but we can't quantify that.

We haven't tested either machine, so read independent reviews before deciding on anything performance related.

Compare the same configuration

The most common mistake with Macs is comparing two listings that are not the same machine. Memory, storage, screen size, colour and chip variant all change the price, and a retailer's cheapest listing often has the smallest configuration. Before comparing, write down the chip, memory, storage and screen size, then check that every listing you compare matches. Also check whether the seller is Amazon, Apple or a third party, because warranty and return handling can differ.

Student discounts and timing

Apple runs an education store with student pricing, and retailers run their own promotions at various times of year. We can't tell you when a given Mac will drop. What you can do is check Apple's current education terms, compare the total with the retailer price for the same configuration, and use a price-history tool to see where today's price sits. If you need the laptop for a deadline, buy when it suits you at a fair price. Waiting for a hypothetical sale is a gamble.

Common mistakes when buying a MacBook

  • Comparing different configurations. Match the memory, storage and screen size.
  • Buying too little memory or storage. They can't be upgraded later.
  • Trusting a "was" price. Compare against recorded price history.
  • Ignoring the seller. Check who sells it and the return terms.
  • Chasing a rumoured sale. Nobody can predict it.

Frequently asked questions

Should I buy the MacBook Air M4 or M5?

Price the same configuration on both. Either handles everyday work, so choose on total price, storage and how long you want to keep it. If you do heavy work, check independent benchmarks.

What is the difference between the M4 and M5 Air?

At launch the M5 started $100 higher at $1,099, doubled base storage to 512GB, and added Apple's N1 wireless chip. Apple also says memory bandwidth is higher. Check Apple's current specs for the full list.

Is 16GB of memory enough?

The M5 base has 16GB. For everyday use it is a comfortable amount; if you edit video or run heavy workloads, consider more and check independent tests.
